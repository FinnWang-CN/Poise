# Fitdays 文件导入与全部身体指标（0.3.0）

## 使用

1. 在 Fitdays 导出当前使用者的 Excel（`.xlsx`），保存到手机。
2. 轻衡 → 设置 → 导入 Fitdays 文件 → 选择 .xlsx 文件。
3. 检查有效条数、日期范围、新增/更新/重复数量和最近 5 条预览。
4. 点击“确认导入”。取消或离开预览不会写入数据。
5. 日历格子仍只显示体重。点击当日记录，展开“查看表格全部数据”查看全部原始字段。
6. 趋势页保留体重、体脂率、BMI 快捷选项；使用“更多身体指标”切换其他指标。

## 支持范围

- 当前支持中文 Fitdays `.xlsx`：前 20 行内有“时间”和“体重”标题，可选“体脂率”。支持多个具有相同列结构的工作表。
- 文件上限 10 MB，单工作表最多 20000 行。不支持旧版 `.xls`、CSV、加密文件或任意其他厂商格式。
- 时间支持本地 `yyyy/MM/dd HH:mm[:ss]`、横线日期以及 Excel 日期类型。
- 体重支持斤、kg/公斤/千克和 lb/lbs，内部统一 kg；数字体重可从列名读取单位，否则按 kg。
- 体脂百分数字符串直接保留百分数；空白、`--`、`—`、`-` 为未测，不补零。
- 原始字段保存在每条记录的 `extras` 中，备份包含这些字段；旧版本备份继续兼容。
- 没有稳定来源 UUID 的 Excel 不能只按时间覆盖：以测量时间、规范化体重和体脂构成导入 ID。同一分钟的不同体脂/体重保留；同一 ID 的其他原始字段更新；相同记录重复导入跳过。
- 更改体重或体脂的源文件记录会作为不同测量保留。可在记录页手动删除不需要的记录。
- 不替换手动或 Health Connect/HealthKit 原始数据。跨来源不自动合并，以免丢失文件里的其他指标。
- 不区分多个使用者档案，导入前必须选择属于当前使用者的文件。

## 字段和趋势

保存原始表格的所有列，包括时间、体重、BMI、体脂率、脂肪量、肌肉率、肌肉量、骨骼肌率、骨量、蛋白质、蛋白量、体水分、含水量、皮下脂肪、内脏脂肪、身体年龄、腰臀比、基础代谢率、去脂体重、标准体重、肥胖等级、体型。

数值字段可独立选择趋势；缺少数值的日期不补零。文字型“体型”“肥胖等级”在详情保留，不画数值折线图。表内存在但全部为缺测的已知数值字段仍可选择，并显示无数据。

趋势取所选指标每天最后一次有效记录。带单位的质量指标由斤/lb 换算为 kg，界面使用斤时相应切换。其他单位为 %、kcal、岁等；不同单位不混画。

BMI 快捷图继续使用当前设置的身高计算；“BMI（文件原值）”使用文件原始值，不根据文件 BMI 猜测或修改身高。记录页编辑体重/体脂不会改写“文件原始值”，重新导入时按预览规则处理。

## 隐私与验证

表格在本机读取和解析，不上传服务器。提供的私人样本没有被打包进 APK 或源码；自动测试通过环境变量仅在本地读取它。

23 项测试通过，包含样本全量解析、斤/kg 换算、缺少体脂、无效日期、同一分钟不同测量、全部字段备份往返、重复导入、导入前不保存、详情原始字段和额外指标切换。系统文件选择器与更新安装仍需真实手机验收。
