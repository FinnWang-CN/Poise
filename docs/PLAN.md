# 轻衡实施计划

## 第一阶段：离线 MVP（本轮）
- [x] Flutter 工程、数据模型、本地持久化与备份格式。
- [x] 月历、日期选择、时段筛选、当日多次记录。
- [x] 体重 / 体脂 / BMI 趋势，7/30/90/365 天范围、目标体重线。
- [x] 记录新增、编辑、删除；身高、目标、公斤/斤设置。
- [x] JSON 导入导出、演示数据（显式启用）、校验和自动化测试。

所有记录以 kg 保存；体脂率为可空值；BMI 按当前设置的身高计算。
日历显示筛选范围内当日最后一次测量；趋势取当日最后一次测量，缺测不补零。
本地数据采用带版本的 JSON；成功写入后才更新界面，失败时显示错误。

## 第二阶段：系统健康数据（后续）

- 保留来源和外部 ID，按来源 + 外部 ID 去重；处理更新与删除同步。
- 真机检查权限撤回、无数据、历史读取限制；配置隐私说明和商店声明。
- Android/iOS 真机与构建验证。

## 第三阶段：可选增强（后续）
- 指定型号蓝牙体脂秤；账号和云端同步；加密备份。

## 验收
- 空数据可直接新增；重启后保留记录和设置。
- kg/斤切换不改变内部记录；BMI 计算和日期/时段边界正确。
- 同日多次测量、缺少体脂、单点图表、空区间均可展示。
- 备份导入先完整校验，再整批替换；操作前明确确认。

## 本轮执行结果

离线 MVP 已完成。数据层采用 shared_preferences + 带版本 JSON，图表采用 fl_chart，日历按参考图定制。
为避免 Web 首次加载依赖外部渲染资源，构建时关闭资源 CDN，中文字体随包提供。
完成 9 项自动化测试和 Web release 构建；已检查手机宽度布局并保存日历、趋势截图。
Android/iOS 安装包构建与真实设备健康数据验证留在第二阶段，未宣称已完成。
